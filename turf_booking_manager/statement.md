# Project Statement

## Problem Statement

Sports turf bookings are often managed manually, which can make it difficult to check available slots and keep track of existing bookings.

The Turf Booking Manager provides a simple console-based solution for managing turf bookings.

## Scope

The project covers:

- Turf selection
- Date selection
- Slot availability
- Customer information
- Booking creation
- Booking search
- Booking cancellation
- Basic reports

The current version does not use an online payment system or permanent database storage.

## Target Users

The main target users are:

- Small turf owners
- Turf managers
- Staff handling sports ground bookings

## High-Level Features

1. Check availability
2. Create bookings
3. View bookings
4. Search bookings
5. Cancel bookings
6. View recent bookings
7. View basic statistics
